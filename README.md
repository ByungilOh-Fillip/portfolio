# 🎬 Cinematic Developer Portfolio

A stunning, film-inspired developer portfolio built with **Astro**, **Tailwind CSS**, and **TinaCMS**. 
Designed to showcase projects through the lens of a classic movie projector, featuring immersive GSAP animations, custom shutter transitions, and a seamless Git-backed CMS.

## ✨ Key Features

- **🎥 Cinematic Projector Transition**: A custom 32-frame film strip transition using CSS `steps()`, complete with shutter strobes, film jitter, and vignette lighting to simulate a real vintage projector.
- **🎞️ Horizontal Film Strip**: A GSAP ScrollTrigger-powered horizontal timeline that displays projects inside continuous cinema film frames.
- **📸 Camera Shutter UI**: A pure CSS 6-blade mechanical aperture that opens and closes smoothly based on user interaction.
- **🎬 Clapperboard Detail Pages**: Project details styled like a movie clapperboard and camera viewfinder.
- **📝 Git-Backed CMS**: Full content management powered by TinaCMS. Just write in the `/admin` UI, and it generates `.md` files directly into the repository.
- **🚀 Automated CI/CD**: Seamless deployment to GitHub Pages via GitHub Actions whenever changes are pushed to `main`.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/) (Static Site Generation for blazing fast performance)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **CMS**: [TinaCMS](https://tina.io/) (Headless, Git-backed CMS)
- **Animations**: [GSAP](https://gsap.com/) & Pure CSS Keyframes
- **Deployment**: GitHub Actions & GitHub Pages

## 🚀 Getting Started

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone <your-repo-url>
cd portfolio
npm install
```

### 2. Local Development
Start the TinaCMS dev server alongside Astro:
```bash
npm run dev
```
- Your site will run on `http://localhost:4321`
- Access the CMS admin panel at `http://localhost:4321/admin`

### 3. Adding Content
You do not need to touch the code to update your portfolio!
1. Go to `http://localhost:4321/admin`.
2. Navigate to **Projects**.
3. Create a new post, fill in the fields (Title, Category, Thumbnail, etc.), and click **Save**.
4. The CMS will automatically generate a Markdown (`.md`) file in `src/content/project/`.
5. Commit and push the changes to GitHub. The site will automatically rebuild and deploy!

## 📂 Project Structure

```text
/
├── .github/workflows/
│   └── deploy.yml        # GitHub Actions CI/CD pipeline
├── public/               # Static assets (fonts, images, icons)
├── src/
│   ├── components/       # Reusable Astro/React components
│   ├── content/          # Markdown files generated by TinaCMS
│   ├── layouts/          # Global layouts (contains the Projector Transition)
│   ├── pages/            # App routes (index, develop, project)
│   └── styles/           # Tailwind and global CSS
├── tina/                 # TinaCMS configuration and schema
├── astro.config.mjs      # Astro configuration
└── tailwind.config.mjs   # Tailwind configuration
```
